# HUT RI 81 Offline Roulette

An offline-first, projector-ready raffle experience for the HUT RI ke-81 celebration at Griya Shanta RT 08.

The approved direction combines an Art Deco casino stage with punk-collage composition, ransom-note typography, and a single oversized roulette. The winning lot remains clear at the center of the wheel while the application guarantees that one lot can win only once per event.

## Planned stack

- Bun
- Astro static output
- Vanilla TypeScript
- CSS and authored SVG geometry
- Installable PWA with local persistence
- Vitest and Playwright
- GitHub and Vercel
